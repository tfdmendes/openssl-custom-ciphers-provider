# Cipher selection

Checked on 18 October 2026.

We selected PRINCE as the block cipher and Rabbit as the stream cipher. Both have published specifications and test vectors that can be checked independently of the provider.

| Cipher | Specification | Parameters used here |
|---|---|---|
| PRINCE | Borghoff et al., ASIACRYPT 2012, [publication](https://orbit.dtu.dk/en/publications/prince-a-low-latency-block-cipher-for-pervasive-computing-applica/) and [included paper](prince_cipher_paper.pdf) | 128-bit key, 64-bit block; ECB, CBC and CTR |
| Rabbit | [RFC 4503](https://www.rfc-editor.org/rfc/rfc4503.html), including Appendix A keystream vectors and Appendix B internal-state vectors | 128-bit key and 64-bit IV in the provider |

PRINCE targets low latency in hardware. Our implementation uses C, so its software throughput is measured separately. Rabbit provides the stream cipher needed to process arbitrary input lengths without padding.

## Standard OpenSSL checks

Neither PRINCE nor Rabbit was found in the following upstream cipher registration files:

| Release | Source checked |
|---|---|
| 0.9.8zh | [crypto/evp/c_allc.c](https://github.com/openssl/openssl/blob/OpenSSL_0_9_8zh/crypto/evp/c_allc.c) |
| 1.0.2u | [crypto/evp/c_allc.c](https://github.com/openssl/openssl/blob/OpenSSL_1_0_2u/crypto/evp/c_allc.c) |
| 1.1.1w | [crypto/evp/c_allc.c](https://github.com/openssl/openssl/blob/OpenSSL_1_1_1w/crypto/evp/c_allc.c) |

The official [OpenSSL 1.0.2](https://docs.openssl.org/1.0.2/man1/enc/#supported-ciphers) and [OpenSSL 1.1.1](https://docs.openssl.org/1.1.1/man1/enc/#supported-ciphers) cipher lists also contain neither name. For OpenSSL 3.6, neither appears in the [default provider](https://docs.openssl.org/3.6/man7/OSSL_PROVIDER-default/#symmetric-ciphers) or [legacy provider](https://docs.openssl.org/3.6/man7/OSSL_PROVIDER-legacy/#symmetric-ciphers) lists.

We also checked the local OpenSSL 3.6.5 installation with only its standard providers:

```bash
openssl version
openssl list -provider default -provider legacy -cipher-algorithms
```

The listing contained no PRINCE or Rabbit entry. Loading `customprov` added `PRINCE-ECB`, `PRINCE-CBC`, `PRINCE-CTR` and `RABBIT`.

These checks support the selection across the releases and sources listed here. They are not an audit of every commit in OpenSSL history. Third-party engines and providers are outside this check.

## Test vector sources

- [PRINCE block vectors](../tests/vectors/prince_kat.h): checked by `test_prince`
- [PRINCE mode vectors](../tests/vectors/prince_modes_kat.h): generated by a separate [Python implementation](../scripts/gen_prince_modes_kat.py), which checks the paper vectors before generating ECB, CBC and CTR results
- [Rabbit vectors](../tests/vectors/rabbit_kat.h): RFC 4503 Appendix A, stored in the RFC's printed order and converted by the tests to the implementation's byte order

Further explanations are in [PRINCE](prince_cipher_explaination.md) and [Rabbit](rabbit_cipher_explaination.md).
